## 참조가 잘 세운 것

- **렌더링 전에 타입이 있는 입력.** 작은 typed 문서를 먼저 쓰고 그로부터 시각물을 만든다. 이 분리가 결과를 검토 가능하고 재렌더 가능하게 만든다.
- **전달 전 검증.** 렌더링이 게이트로 막힌다. 후보가 스키마·레이아웃·여백 검사를 통과해야 마지막 정상 출력을 대체하며, 실패하면 스택 트레이스 대신 지원되는 수리 목록이 담긴 기계 판독 진단을 돌려준다.
- **자체 완결 출력.** 결과는 빌드 단계도 네트워크 의존도 없는 HTML 파일 하나다. 남에게 보내도 그대로 동작한다.
- **절제되고 정직한 인터랙션.** 읽기 조작은 작성된 사실을 재사용하며, 위상을 지어내거나 런타임 영향을 주장하지 않는다.

## 이 패키지가 가져온 것

| 아이디어 | 이 패키지에서의 모습 |
|---|---|
| 렌더링 전 typed 입력 | 닫힌 스키마를 가진 `explanation.json`. [`explanation-view-schema.md`](explanation-view-schema.md)에 있다 |
| 전달 전 검증 | 렌더러가 파싱·스키마·토큰·쓰기 오류에서 실패를 닫고, 원자적으로 써서 실패한 실행이 이전 출력을 보존한다 |
| 자체 완결 출력 | HTML 파일 하나, 인라인 스타일과 스크립트, 외부 리소스 없음, 네트워크 없음 |
| 절제된 인터랙션 | 읽기 조작은 정확히 다섯 개. [`../rules/output-artifacts.md`](../rules/output-artifacts.md)에 있다 |
| 결정론적 산출물 근거 | 같은 입력에 대해 생성 HTML이 바이트 단위로 동일하다 |

## 이 패키지가 일부러 가져오지 않은 것

- **다이어그램 타입 전체.** 참조는 다섯 종류를 그린다. 설명은 모양이 하나이므로 렌더러 하나면 충분하다.
- **큰 뷰어 기능 표면** — 검색, 상·하류 도달 추적, 시맨틱 챕터, 프레젠테이션 스테이지, 내보내기 메뉴, 공유 카드. 이것들은 시스템 지도를 위한 것이지 설명을 위한 것이 아니다.
- **참조에 대한 런타임 의존.** 이 패키지는 자체 렌더러와 템플릿을 함께 배포한다. 여기서 참조가 설치되어 있어야 하는 것은 없고, 참조를 호출하지도 않는다.
- **참조의 뷰어 템플릿.** 미리 만들어진 뷰어를 재사용하면 이 스킬에 필요하지 않은 큰 자산과 스타일 체계를 끌어온다.

## 비교 규칙

참조에서 코드, 템플릿, 문구를 복사하지 않았다. 관계는 설계 참조이며 출처 기록을 위해 여기에 남긴다. 이 패키지가 참조와 같거나 낫다고 주장하지 않는다. 비교에는 같은 과제 집합, 같은 런타임, 같은 검토자, 공개된 영수증이 필요하고 그중 어느 것도 없다.
