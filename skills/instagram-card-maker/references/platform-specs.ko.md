# 플랫폼 규격

> 영어 정본: [`platform-specs.md`](platform-specs.md)

형식을 고르기 전에 읽습니다. 이 파일은 이미지 규격, 형식 프리셋, 대비 기준을 다룹니다. 앱 경로와 API 경로를 나누고, 플랫폼 규칙과 이 패키지의 디자인 기본값을 나눕니다.

## 1. 앱 대 API

인스타그램은 앱 안 게시 경로와 게시 API를 따로 문서화하며 둘은 다릅니다. 이 스킬은 앱 경로용 이미지를 만들고 게시하지는 않습니다.

| 항목 | 앱(앱 안 게시) | API(콘텐츠 게시) |
|---|---|---|
| 사진 너비 | 320~1080 px | (API 규격) |
| 가로세로 비율 | 1.91:1 ~ 3:4 | 4:5 ~ 1.91:1 |
| 형식 | (앱이 업로드를 처리) | JPEG |
| 크기 상한 | (앱은 명시 없음) | 8 MB |
| 캐러셀 항목 | 사진·동영상 최대 20개, 캐러셀당 캡션 하나 | 최대 10개 |

한 열의 값을 다른 열을 지배하는 것처럼 다루지 않습니다. API 제한은 앱의 제한이 아니고 앱의 제한도 API의 것이 아닙니다.

## 2. 형식 프리셋

| 프리셋 | 크기 | 비율 | 사용 시점 |
|---|---|---|---|
| 기본 | 1080×1350 | 4:5 | 패키지 기본값이며 보수적이고 흔한 선택입니다. |
| 세로(앱 전용) | 1080×1440 | 3:4 | 사용자가 요청하거나 근거가 뒷받침할 때만. 앱 경로는 3:4를 받고 API 경로는 받지 않습니다. |
| 정사각 | 1080×1080 | 1:1 | 사용자가 요청하거나 근거가 뒷받침할 때만. |

4:5를 유일한 인스타그램 형식이라 부르지 않습니다. 그것은 이 패키지의 기본값이지 플랫폼 규칙이 아닙니다.

## 3. 대비 기준

이 패키지는 W3C 웹 콘텐츠 접근성 지침의 대비 최소값(SC 1.4.3)을 디자인 기준으로 씁니다. 글자와 이미지 속 글자에 4.5:1, 큰 글자에 3:1입니다.

- 이것은 여기서 디자인 목표로 채택한 웹 접근성 표준입니다. 인스타그램 규칙이 아니며 인스타그램이 강제하지 않습니다.
- 컴포저는 구조적으로 목표를 충족합니다. 글자가 완전 불투명한 `#151515` 패널 위 흰 글자로 놓여 대비가 뒤 사진에 좌우되지 않습니다.

## 4. 타이포그래피와 레이아웃은 기본값

한국어 글꼴, 여백, 블러 양, 왼쪽 하단 제목 배치, 카드 수는 이 패키지의 기본값이자 사용자의 선호입니다. 어느 것도 플랫폼 규정이 아닙니다. 사용자가 규칙을 물으면 기본값이라고 밝힙니다.
