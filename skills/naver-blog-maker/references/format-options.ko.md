# 글 양식 옵션: plain과 rich

> 영어 원본: [`format-options.md`](format-options.md)

[`../rules/intake.ko.md`](../rules/intake.ko.md)에서 양식을 고른 뒤 읽습니다. 이 문서는 전달 형식을 정하며 네이버 조작이나 발행 권한을 부여하지 않습니다.

## 1. 전달

- `plain`: 제목, 본문 마커, 해시태그가 든 `text` 펜스 초안 하나를 제공합니다. 제목 입력란과 태그 설정에는 별도 입력해야 한다고 안내합니다.
- `rich`: 제목, 카테고리(알고 있을 때), 태그를 본문 HTML과 분리합니다. 파일 전달이 가능하면 HTML 파일과 렌더링된 미리보기를 제공합니다. 불가능하면 `html` 펜스에 소스를 제공하되 서식 있는 클립보드가 아니라 소스임을 명시합니다.
- 서식 붙여넣기는 렌더링된 내용을 HTML 클립보드 데이터(`text/html`)로 복사해야 합니다. 코드 블록의 태그를 문자로 복사하는 것과 다릅니다. 코드 블록 복사 버튼이 서식을 보존한다고 약속하지 않습니다. 렌더링·HTML 클립보드 경로가 없으면 한계를 밝히고 소스와 plain 대안을 제공합니다.
- 이미지 생성 JSON 프롬프트와 발행 안내는 본문 HTML 밖에 둡니다. 이미지 주소를 모르면 눈에 보이는 삽입 안내를 남깁니다. URL을 만들거나 프롬프트를 이미지라고 말하지 않습니다.

## 2. 지원 기능과 제한사항

| 기능 | 보고된 결과 | 전달 규칙 |
|---|---|---|
| 굵기, 글자색, 배경 강조, 밑줄 | 유지 | `strong`, 인라인 색·배경 스타일의 `span`, `u` |
| 가운데·오른쪽 정렬 | 유지 | 인라인 `text-align` |
| 인용구, 구분선 | 네이버 전용 컴포넌트로 변환 | `blockquote`, `hr` |
| 순서 있는·없는 목록 | 유지 | `ol`, `ul`, `li` |
| 링크 | `se-link`로 변환, `data-href`에 주소 유지 | 일반 `a href`를 제공하고 네이버 내부 마크업을 직접 만들지 않음 |
| 공개 HTTPS 이미지 | 사진 컴포넌트로 변환, 정렬·너비 유지 | 실제 접근 가능한 HTTPS 주소를 가진 `img` |
| 표 | 편집 가능한 네이버 표로 변환 | 테두리, 셀 배경색, 헤더, 셀 내부 인라인 서식, 너비 100%, 셀 정렬, `colspan`, `rowspan` |
| Data/Base64 이미지 | 제거되고 주변 글만 남음 | `data:image` 사용 금지 |
| 취소선 `s` | 일반 글자로 정규화 | 에디터에서 직접 적용하도록 안내 |
| `pre/code` | 소스코드 컴포넌트가 아닌 일반 글자 | 에디터에서 직접 적용하도록 안내 |

표 변환 뒤 행·열 추가, 셀 병합, 행·열 분할, 너비·높이 조절 기능이 나타났다고 보고됐습니다. 편집 가능한 표라는 근거이며 임의로 중첩한 HTML까지 보장하지는 않습니다.

## 3. HTML 작성 경계

사용자가 권장한 태그 범위를 사용합니다. `p`, `h2`, `h3`, `strong`, `u`, `span`, `ul`, `ol`, `li`, `blockquote`, `hr`, `table`, `thead`, `tbody`, `tr`, `th`, `td`, `img`, `a`. 외부 CSS보다 인라인 스타일을 쓰고 깊은 중첩보다 단순한 형제 블록을 우선합니다. 이 목록은 권장안입니다. 정확한 소제목 크기와 빈 줄 보존은 개별 테스트 결과가 보고되지 않았습니다.

본문과 속성값을 이스케이프하고 스크립트, 이벤트 핸들러, 실행 가능한 URL 스킴을 제외합니다. 표의 병합 범위와 셀 수를 일치시킵니다. 문장 규칙의 장식 상한을 따릅니다. 지원되는 서식을 모두 사용할 필요는 없습니다.

공개 HTTPS 이미지 주소는 제공받거나 확인한 것만 씁니다. 로컬 이미지는 사용자가 업로드하거나 별도로 요청한 업로드 작업이 필요합니다. 이 스킬이 몰래 외부 서버에 파일을 올리지 않습니다. Base64로 대신하지 않습니다. 긴 글은 순서가 표시된 본문 조각으로 나눠 붙이고 블록 중복·누락을 확인할 수 있게 합니다.

## 4. 별도 에디터 작업

본문 붙여넣기는 제목, 카테고리, 태그, 공개 설정, 댓글, 공감, 예약, 발행을 설정하지 않습니다. 이 항목은 전달 메모에 분리하고 본문 HTML이 설정한다고 말하지 않습니다.

동영상, 스티커, 파일, 일정, 수식, 장소·지도, 책, 글감, 외부 콘텐츠, 소스코드 컴포넌트는 별도 요청과 지원 기능이 없는 한 사용자가 에디터에서 직접 처리합니다. 자동화 권장안을 전달받았다고 자동화 구현 권한이 생기지는 않습니다.

발행 전 사용자가 렌더링된 본문이나 에디터 DOM에서 블록 중복·누락, 링크, 표 병합, 이미지 위치, 제목·태그 분리를 확인합니다. 발행은 사용자가 수행합니다.
