# 네이버 블로그 키워드·의도 리서치

> 영어 원본: [`keyword-research.md`](keyword-research.md)

[`../rules/post-workflow.ko.md`](../rules/post-workflow.ko.md) 2단계에서 사용자가 목표 검색어를 정하지 않았거나, 고른 검색어가 블로그 글에 너무 넓거나 너무 상업적으로 보일 때 읽습니다. 실무자가 하는 일, 공개 페이지에서 읽을 수 있는 부분, 어떤 숫자가 경험칙인지 정리했습니다.

## 1. 목표 검색어의 조건

- **의도 슬라이스 하나.** 2024-02부터 네이버는 복합 검색어를 의도 단위로 나누고 스마트블록마다 따로 랭킹합니다(`캠핑` → 캠핑요리 / 캠핑용품 / 캠핑장소). 검색어는 글이 답하는 슬라이스를 지목해야 합니다.
- **블로그 글이 실제로 뜨는 슬라이스.** 구매·예약 검색어는 첫 화면이 쇼핑, 플레이스, 광고인 경우가 많고 블로그 글은 아래쪽 후기/비교/인기글 블록에 나오거나 아예 안 나옵니다. 쓰기 전에 봅니다.
- **작성자의 주제 레인 안.** C-Rank 신뢰는 주제별입니다. 블로그가 다룬 적 없는 레인의 좋은 글은 출처 신뢰 없이 시작합니다.

## 2. 절차

1. **확장**: 시드에 수식어를 붙입니다. 장소(`강남`, `제주`), 대상(`아이와`, `혼자`), 모델·변형, 문제(`누수`, `소음`), 가격(`가격`, `비용`), 계절, 과제어(`후기`, `비교`, `추천`, `방법`, `주의`). 자동완성, 연관검색어, 함께 많이 찾는 검색어는 브라우저에서만 보입니다. 브라우저 도구로 모으거나 사용자에게 붙여 달라고 합니다.
2. **공급과 수요를 따로 측정**합니다.
   - 공급: 정확한 문구와 일치하는 블로그 문서가 이미 몇 개인지.
   - 수요: 시간에 따른 상대 관심도, 계절성, 기기 비율.
   - 후보를 두 축으로 비교하고 실제 수요가 있으면서 공급이 얇고 약한 슬라이스를 고릅니다. 비율은 선별 보조이지 랭킹 확률이 아닙니다. 문서수와 검색수는 수집 범위가 다릅니다.
3. **실제 검색 결과를 읽습니다**(상위 후보 2~3개). 블록 순서, 블록 제목, 블로그 블록이 첫 화면에 있는지, 상위 3개 글이 무엇을 약속하고 무엇이 빠졌는지(아쉬운 점 없음, 가격 기준 없음, 오래된 날짜). 그 빈틈이 글의 각도입니다.
4. **한 줄로 결정**하고 초안과 함께 둡니다. `../rules/post-workflow.ko.md` §2의 6필드 결정 줄 — `검색어 / 의도 슬라이스 / 주 유형 / 보조 유형 / 목표 / 근거` — 에 이 절차의 문서수·검색 결과 메모를 담아 씁니다.

## 3. CLI 없이 공급과 수요 읽기

세 측정값 모두 방문자가 열 수 있는 공개 페이지에 있습니다.

| 필요 | 어디서 | 숫자의 뜻 | 아닌 것 |
|---|---|---|---|
| 공급 대리값 | 정확한 문구의 네이버 블로그 검색 결과 페이지(블로그 탭 결과 수) 또는 공개 키워드 도구의 문서수 열 | 문구와 일치하는 누적 블로그 문서 | 월간 발행량 아님, 포화도 아님 |
| 수요 형태 | 네이버 데이터랩 검색어트렌드(<https://datalab.naver.com/keyword/trendSearch.naver>): 후보 2~5개, 모바일 vs PC, 주 단위 비교 | 비교 그룹 안 최대값 = 100인 상대 지수 | 검색량 아님 |
| 상위 글 조사 | 문구의 상위 블로그 결과 10~20개 | `../rules/topic-research.ko.md` §2 빈틈 분석용 제목·첫 화면·소제목 | 통합검색에 보이는 스마트블록 순서 아님. 그건 따로 읽음 |

로그인 없이는 불가: 절대 월간 검색량, 클릭, CTR(네이버 검색광고 키워드도구). 절대 만들어내지 않습니다.

## 4. 실무자가 쓰는 외부 도구

| 도구 | 제공 | 접근 | 주의 |
|---|---|---|---|
| 네이버 검색광고 키워드도구 | PC/모바일 월간 검색수, 클릭, CTR, 경쟁도 | 광고주 로그인 | 문서수 없음 |
| 네이버 데이터랩 검색어트렌드 | 기간·기기·성별·연령별 상대 트렌드 | 공개 | 상대값. 검색량 아님 |
| 블랙키위 | 검색량, 월간 발행량, 포화도, 연관어, 섹션 배치 | 등급제(게스트 / 무료 / 유료) | 한도가 바뀜. 브라우저에서 확인 |
| 키워드마스터 (WhereIsPost) | 검색량, 블로그 문서수, 문서수/검색량 비율, CSV | 공개 | 자체 페이지가 두 수치의 범위가 다르다고 경고 |

## 5. 경험칙과 근거 등급

| 경험칙 | 등급 | 메모 |
|---|---|---|
| 고르기 전에 검색량과 문서수 비교 | observed (5개 출처) | 방법이지 임계값이 아님 |
| 최신성이 중요하면 누적 문서수보다 월간 발행량 | observed (3개 출처) | — |
| 계절 글은 트렌드가 오르기 전에 발행 | observed | 데이터랩은 공식. 선행 기간은 아님 |
| `문서수 / 월 검색량 ≤ 1`이 좋은 목표 | 단일 출처 | 표현이 내부적으로 모순. 선별용만 |
| `모바일 월 200~1,000회`가 작은 블로그에 맞는 구간 | 단일 출처 | 한 작성자의 독자 기준 |
| 쇼핑·플레이스가 많은 상업 검색어는 독자가 원하는 후기·비교가 아니면 블로그 목표로 약함 | observed (2개 출처) | 실제 검색 결과로 확인 |
