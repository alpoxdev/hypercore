# Rich HTML 조립

> 영어 원본: [`rich-html-template.md`](rich-html-template.md)

rich 결과물을 만들 때마다 읽습니다. [`../assets/rich-post.html`](../assets/rich-post.html)을 출력 틀로, [`../assets/rich-blocks.html`](../assets/rich-blocks.html)을 블록 모음으로 사용합니다. 의존성 없는 HTML이며 빌드, 외부 CSS, 이미지 서비스가 필요하지 않습니다.

## 1. 파일 조립

1. 출력 틀을 요청된 위치의 새 `.html` 파일로 복사합니다. 제공된 예제 원본과 스킬 에셋을 덮어쓰지 않습니다.
2. `#post-title`, `#post-category`, `#post-tags`에 이스케이프한 텍스트를 넣습니다. 본문이 아니라 별도 에디터 입력 항목입니다.
3. `#sample`의 자식만 완성된 글로 교체합니다. 블록 모음에서 알맞은 `template`의 **내용만** 복사합니다. `template` 래퍼, 예제 문구, 안 쓰는 예시는 넣지 않습니다.
4. 복사할 콘텐츠의 스타일은 인라인으로 둡니다. 표 셀마다 테두리와 여백이 필요합니다. 페이지 스타일시트에만 있는 클래스는 본문 HTML과 함께 전달되지 않습니다.
5. 이미지와 링크에는 제공받거나 확인한 실제 HTTPS 주소를 씁니다. 이미지 주소가 없으면 빈 `img`, 예제 URL, Base64 대신 실제·생성 이미지 마커를 둡니다. 생성 JSON과 발행 메모는 `#sample` 밖의 `#author-notes`에 넣습니다.
6. 출력 틀의 버튼과 스크립트를 유지합니다. 본문에는 스크립트, 이벤트 핸들러, 실행 가능한 URL이 없어야 합니다. 복사용 스크립트는 본문 밖에 두고 복사 선택 범위에 넣지 않습니다.

## 2. 블록 선택

| Template ID | 용도 |
|---|---|
| `paragraph` | 문단과 명시적인 `br` 줄바꿈 |
| `headings` | `h2` / `h3` 소제목. 네이버 제목 입력란과는 다름 |
| `inline-styles` | 굵기, 기울임, 밑줄, 글자·배경색, 글자 크기 |
| `alignment` | 왼쪽·가운데·오른쪽 정렬 문단 |
| `quote-divider` | 인용구와 구분선 마크업 |
| `lists` | 순서 있는·없는 목록 |
| `link` | 목적지가 드러나는 일반 링크 |
| `table` | 셀별 인라인 테두리·서식을 가진 기본 표 |
| `merged-table` | 유효한 2열 `colspan` / `rowspan` 예제 |
| `image` | HTTPS 사진, 크기, 가운데 캡션 |
| `image-slot` | 없는 실제 자료 |
| `generated-image-slot` | JSON 프롬프트와 연결할 설명 그림 자리 |

취소선, 강조 박스 모양 보존, 정확한 문단 간격, 네이버 소스코드 컴포넌트는 제공된 샘플에서도 보장되지 않습니다. 정상 기능인 것처럼 기본 블록에 넣지 않습니다.

## 3. 복사 계약

사용자가 완성된 HTML을 브라우저에서 열고 **서식 콘텐츠 복사**를 누릅니다. 클릭 처리에서 `Range.selectNodeContents(sampleEl)`로 렌더링된 본문만 선택한 뒤 `document.execCommand('copy')`로 브라우저의 서식 복사를 요청합니다. 제공된 작동 샘플과 같은 방식입니다. 소스 텍스트를 복사하는 `writeText(innerHTML)`로 바꾸지 않습니다.

이 구형 복사 API는 브라우저나 샌드박스에서 차단될 수 있습니다. 반환값이 true일 때만 성공을 표시합니다. false이거나 예외가 나면 본문 선택을 유지하고 Ctrl+C / ⌘C 수동 복사를 안내합니다. 실패를 성공으로 표시하지 않습니다. **HTML 소스 복사** 버튼은 소스 전용임을 명시합니다.

ChatGPT 미리보기가 스크립트를 막으면 완성된 HTML 파일을 내려받아 브라우저에서 열도록 안내합니다. 파일 전달이 불가능하면 저장할 수 있는 완전한 HTML 문서를 제공하고 코드 펜스 복사 버튼은 서식 복사가 아니라고 알립니다. rich 요청을 말없이 plain 초안으로 바꾸지 않습니다.

## 4. 결과물 검증

- 파일을 열어 데스크톱과 좁은 화면을 확인하고 예제 문구, 미확정 URL, 넘침, 표 병합을 점검합니다.
- 서식 버튼을 눌러 `#sample`만 선택되는지 확인합니다. 제목·태그·버튼·프롬프트가 섞이지 않아야 하고 상태 문구는 실제 복사 결과와 일치해야 합니다.
- 브라우저 입력이 가능하면 로컬 임시 편집 영역에 붙여넣어 `strong`, 링크, 표 병합을 확인합니다. 로컬 클립보드 검증이지 네이버 변환 검증은 아닙니다.
- 복사 차단 경로도 별도로 확인하여 수동 복사 안내가 나오는지 점검합니다.
- 네이버 붙여넣기는 사용자가 확인합니다. 템플릿 조립에 로그인·업로드·발행은 포함되지 않습니다.

유지보수: 저장소 루트에서 `node --test skills/naver-blog-maker/assets/evals/rich-copy.test.cjs`를 실행합니다. Node 내장 기능만 필요하며 복사 처리 검사 3개가 모두 통과해야 합니다. 실패하면 출력 틀 변경을 완료하지 않습니다. 모의 환경 검사는 브라우저 클립보드 검증을 보완하며 대신하지 않습니다.
