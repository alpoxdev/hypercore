# 훅 라이브러리: 제목, 서두, 마무리, 어휘

> 영어 원본: [`hook-library.md`](hook-library.md)

제목, 첫 화면, 마무리, 행동 유도 문장을 쓸 때 읽습니다. 모든 패턴은 두 가지로 평가했습니다. 네이버 자체 가이드가 허용하는지([`../rules/naver-ranking-contract.ko.md`](../rules/naver-ranking-contract.ko.md) R4, R6, R9)와 사람이 쓴 글로 읽히는지입니다. 한 실무자의 전환 지향 프롬프트를 일반화하되 두 시험을 모두 통과한 것만 남겼습니다.

## 1. 모든 훅 뒤에 있는 규칙 하나

훅은 **첫 화면이 지키는 구체적인 약속**입니다. 네이버는 낚시성을 제목·본문과 검색어의 불일치로 정의하고 독자가 제목으로 내용을 예측할 수 있어야 한다고 요구합니다. 그러므로:

- 구체적인 것을 약속합니다(결정, 직접 측정한 수치, 조건, 자신이 했던 실수).
- 첫 3~5문장 안에 이행합니다.
- 주제를 숨기지 않고("이것", "비밀", "충격") 통계를 만들어내지 않습니다("97%가 모르는").

## 2. 제목 패턴

| 패턴 | 네이버용 예시 | 작동 이유 | 위험 |
|---|---|---|---|
| 숫자가 있는 결정 경계 | `직접 써 본 무선청소기 3개, 반려동물 털 기준으로 고른 1개` | 범위가 한눈에 보이고 숫자가 실제 개수 | 개수를 꾸미거나 채우면 위험 |
| 구체적 호기심 간극 | `성수역 3번 출구 카페, 재방문 전 확인할 한 가지` | 주제를 밝히고 본문이 첫머리에 여는 답만 남김 | 간극이 막연하면 중간 위험. 본문이 답을 미루면 실패 |
| 나와 관련 있는 질문 | `아이와 비 오는 날, 실내놀이터와 박물관 중 어디가 나았을까?` | 두 현장 실험에서 질문형 제목이 서술형보다 나았음. 본문이 답하는 실제 결정이어야 함 | 수사적 질문이면 신뢰도 하락 |
| 확인한 항목을 밝힌 경험/후기 | `제주 렌터카 2박 3일 후기: 보험보다 먼저 확인한 항목` | 직접 경험 근거를 신호. D.I.A. 경험 정보와 맞음 | 경험이 실제가 아니거나 협찬 미공개면 실패 |
| 근거 있는 경고 | `누수 업체 부르기 전, 사진으로 먼저 확인할 3가지` | 뉴스 실험에서 부정 프레임이 클릭을 높임. 피해가 실제이고 예방책이 따를 때만 안전 | 피해를 과장하거나 본문이 예방 대신 판매하면 고위험 |
| 결론 먼저 | `소형 가정이면 A, 소음 때문에 B는 제외: 3개월 사용 결론` | 검색 의도의 불확실성을 줄임 | 본문 근거가 결론과 어긋나면 실패 |
| 축을 밝힌 비교 | `강남 임플란트 가격 비교, 개당 가격보다 먼저 본 3가지` | 스마트블록 비교 의도와 맞음 | 규제 분야(의료·금융)는 중간 위험. 모든 주장에 출처 필요 |

길이: 20~35자, 목표 검색어는 앞쪽(모바일 잘림), 이모지 없음, 키워드를 쌓은 `[]` 괄호 없음.

## 3. 서두 패턴 (첫 화면)

순서: **구체적 공감 한 문장 → 답이나 발견 → 그렇게 말할 수 있는 이유 → 나머지가 다루는 범위**.

| 단계 | 예시 | 메모 |
|---|---|---|
| 구체적 공감 | `저도 처음엔 주차 때문에 망설였어요.` | 한 문장. "많은 분들이 고민하시죠"가 아니라 실제 상황을 지목 |
| 답 먼저 | `결론부터 말하면 평일 11시 전에는 괜찮았습니다. 주말은 달랐어요.` | 시드 프롬프트에서 유지: "바쁘실 여러분을 위해 결론부터". 그다음 실제로 결론을 말함 |
| 신뢰 근거 | `3주 동안 네 번 방문해서 시간대별로 확인했습니다.` | 날짜, 기간, 횟수, 가격 기준, 출처 |
| 범위 약속 | `아래에서는 시간대별 주차 상황, 대안 주차장 2곳, 비용을 정리했습니다.` | 실제 섹션 목록. "3분만 집중해 주세요" 압박 없음 |
| 공개(해당 시) | `이 글은 ○○에서 제품을 제공받아 작성했습니다. 장점 2가지와 아쉬운 점 1가지를 그대로 적었습니다.` | 평가 문장보다 앞에, 쉬운 말로 |

시드 프롬프트에서 고쳐 쓰면 쓸 수 있는 것:

- `지금 이 글을 보고 계신 분께서는 ~를 알아보고 계실 텐데요` → `~를 알아보는 중이라면, 제가 확인한 기준부터 보세요.`
- `제가 직접 '이것'의 정체를 알려드릴까 해요` → `제가 [기간/조건]에서 확인한 내용을 먼저 적겠습니다.`
- `딱 1분만 집중해 주시길` → `먼저 30초 요약을 적고 근거는 아래에 붙였습니다.` (요약이 실제로 있을 때만)
- `그리고 위와 같은 사례의 문제는 1가지 공통점을 가지고 있는데요` → 유지. 다음 단락에서 공통점을 증명할 때만.
- `~ 이유만으로 ~하면 안 되는지, 어떤 기준으로 선택해야 하는지` → 유지. 경고와 기준을 함께 주는 강한 틀.

시드 프롬프트에서 버린 것(숨김, 만들어낸 숫자, 독자 심리 단정, 압박): `'이것'이 무엇일지 궁금해지셨을 거예요`, `97%는 … 클릭했을 겁니다`, `수천만 원의 비용을 지출할 수 있는 상황`, `저희 블로그를 참고하시면`, `3분만 집중해주세요`.

## 4. 어휘: 유지, 수정, 삭제

| 시드 분류 | 판정 | 규칙 |
|---|---|---|
| 숨겨진 정보(`아무도 몰랐던`, `1%만 아는`, `97%가 모르는`, `비밀`) | 삭제 | 숨김과 만들어낸 배타성이 낚시성의 정의 |
| 긴급성(`지금`, `바로`, `당장`, `하루라도`) | 실제 기한이 없으면 삭제 | 거짓 긴급성은 기만 콘텐츠 |
| 시간 주장(`몇 초 만에`, `3초 안에`) | 측정한 시간으로 수정 | `설치에 12분 걸렸습니다` |
| 신뢰 어휘(`책임지는`, `매일 쓰는`, `실패하지 않는`, `인생을 바꾼`, `확실한`) | 수정 또는 삭제 | 사실로 보여줌. 절대 표현(`인생을 바꾼`, `확실한`)은 삭제 |
| 개수(`총정리`, `TOP 3/5/7`, `한 가지`, `하나만`) | 실제 개수면 유지 | 개수 = 평가한 집합의 크기 |
| 두려움(`손해 보는`, `후회하는`, `큰일 나는`, `피해야 할`) | 구체적이고 근거 있는 피해에만 수정 적용 | 피해와 조건을 말하고 예방책을 제공 |
| 간편함(`누워서도`, `혼자서도`, `누구나`, `~없이도`) | 검증하고 조건을 붙였을 때만 수정 적용 | 전문성이 필요한 일에 `혼자서도`는 위험 |
| 강조(`단`, `절대`, `무조건`, `반드시`, `미친`, `압도적인`) | 삭제 | 근거 없는 강조는 광고로도 AI로도 읽힘 |
| `무료` | 실제로 무료일 때만 유지 | — |
| `~하지 마세요` | 근거 있는 경고 제목으로 유지 | — |
| `~살 때 자주 듣는 질문` | 질문이 실제일 때 유지 | — |

시드의 "검증된 후킹 문구" 중 바로 버린 것: `한번 믿어보세요`, `100% 후회합니다`, `한국인 99%가 모르는`, `미친 내용을 발견했어요`, `저 오늘 100만원 벌었어요`, `고민 없애드립니다. 종결`, `3가지 비밀`, `여기, ~가 있습니다`, `충격적인 / (감동주의)`, `수준 ㄷㄷ`, `진실을 폭로합니다 (삭제예정)`.

## 5. 마무리 패턴

마무리는 세 가지를 합니다. 독자가 이제 내릴 수 있는 결정을 다시 말하고, 결정이 달라지는 조건을 밝히고, 범위가 정해진 다음 단계 하나를 제시합니다. "새로운 시각", "성공의 첫걸음", "행운을 빕니다"는 없습니다.

시드에서 유지(그대로 또는 살짝 줄여서):

- `여기까지 읽어보셨다면, 어떤 기준으로 ~할지 감이 조금은 오셨을 듯한데요.` 그다음 실제 기준을 한 줄로.
- `만약 추가로 더 알고 싶으신 부분이 있다면, 아래 링크를 확인해 보시는 것도 좋습니다.` 링크는 구체적인 1차 출처여야 함.
- `실제 적용해보며 느낀 점을 나중에 공유해주시면 큰 도움이 될 것 같습니다.` 칭찬이 아니라 사용 피드백을 요청.
- `혹시라도 궁금한 부분이 있으시면, 추가 자료를 통해 더 깊이 알아보실 수 있습니다.` 자료를 명시.

수정: `지금 바로 적용해 보신다면` → `지금`을 실제 과제에 연결. `언제든지 찾아주세요` → 범위가 정해진 연락 경로. `눈탱이 맞는 상황을 예방` → 가격 비교 근거.

삭제: `큰 변화를 경험하게 될 것입니다`, `새로운 시각을 가지셨다면`, `성공의 첫걸음`, `어느새 이 글이 끝났네요`, `더 유용한 정보로 찾아뵙겠습니다`, `확신을 가지고 … 시작은 이 글로부터`, `이제는 실행만 남았습니다. 행운을 빕니다!`.

## 6. 전환형 행동 유도 (전환형 모드만)

- 행동 유도는 하나, 마지막에, 가치를 전달한 뒤에.
- 브랜드의 바람이 아니라 독자의 다음 결정으로 표현: `견적을 비교할 때 위 세 항목을 먼저 물어보세요. 저희 기준표는 [링크]에 있습니다.`
- 브랜드 사실(가치입증)은 사용자 입력에서 **그대로** 넣습니다. 스킬은 자격, 건수, 수상, 가격을 만들어내지 않습니다.
- 상업적 관계(자사, 협찬, 제휴)는 서두에서 공개하고 행동 유도에서 처음 드러나게 하지 않습니다.

## 7. 발행 전 적신호 점검

다음 중 하나라도 있으면 초안을 실패로 처리합니다. 만들어낸 퍼센트나 통계, 숨긴 경제적 관계, 절대적 보장, 가짜 기한, 첫 화면이 이행하지 않는 제목, 일반적 행동 유도(`도움이 되셨다면 공감/댓글`), 네이버 에디터에 붙인 마크다운 `**굵게**`나 `#` 제목.
