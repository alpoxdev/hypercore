# 검증

> 영어 원본: [`validation.md`](validation.md)

**목적**: 전달 전 모든 초안에 실행하는 자체 점검과 이 스킬이 바뀔 때 실행하는 패키지 점검입니다. 각 항목은 모델이 세거나 볼 수 있는 것입니다. 점수도 스크립트도 없습니다.

## 1. 초안 점검표

### 강제 규칙 (하나라도 실패하면 전달 중단)

- [ ] **의도 하나, 레인 하나.** 글이 지정된 검색어 슬라이스 하나에 답하고 주제가 접수 때 기록한 작성자 블로그 레인에 맞음. (R1)
- [ ] **모든 섹션에 근거.** 각 섹션에 확인 가능한 상황(날짜, 장소, 기간, 가격 기준, 수량, 조건) 하나나 인용 출처가 있고, 최소 한 섹션이 아쉬운 점, 예외, 실패를 밝힘. (R2)
- [ ] **삽입된 키워드 없음.** 목표 검색어가 제목에 한 번, 본문에서는 문장이 필요로 하는 자리에만 나옴. 본문을 소리 내 읽어 독자가 알아챌 반복이 없고, 숨긴 키워드나 무관한 키워드가 없으며, 해시태그는 7개 이하로 모두 정확함. (R3)
- [ ] **제목 약속 이행.** 제목이 암시하는 구체적 답이나 발견이 첫 3~5문장 안에 있음. 숨김 어휘(`이것`, `비밀`, `충격`), 만들어낸 통계, 가짜 기한 없음. (R4)
- [ ] **원본만.** 제공받은 업체 원고 없음, 다른 글에도 나오는 템플릿 블록 없음, 다른 글의 사진 세트를 가리키는 이미지 마커 없음. (R5)
- [ ] **공개와 링크.** 전환형이나 협찬·제휴 관계는 첫 단락에서 쉬운 말로 공개하고, 모든 외부 링크가 어디로 가는지 밝힘. (R6)
- [ ] **리서치 실행, 지어낸 것 없음.** 브리프에 사실이 없었으면 사실 묶음에 출처 있는 사실(`URL | 날짜`)과 상위 3편 빈틈 분석이 있고, 작성자가 주지 않은 직접 경험 주장은 모두 예시가 붙은 `[확인 필요: …]` 슬롯이지 문장이 아님.
- [ ] **인라인 이미지 마커.** 제목 뒤 커버 마커 하나와 사진으로 증명할 주장마다 `[이미지: 무엇을 찍을지 | 캡션]` 하나가 본문의 그 위치에 있음. 스톡·캡처·재사용 세트 제안 없음.
- [ ] **텍스트 블록 전달.** 글이 `text` 코드 펜스 하나임: 첫 줄 제목, 마지막 줄 해시태그, 순수 텍스트만(`#`, `**`, 목록 문법 없음), 모든 마커가 그 안에.
- [ ] **사람이 검토할 초안 하나.** 글은 정확히 한 편, 묶음 발행용 변형 없음, 사실이 빠진 자리는 채우지 않고 `[확인 필요]` 표시를 남김. (R7)
- [ ] **브랜드 사실 원문 유지.** 전환형: 모든 가치입증 문장이 사용자 입력과 글자 단위로 일치하고 자격, 건수, 수상, 가격을 더하지 않음.
- [ ] **반응 조작 없음.** 댓글·좋아요·구독 유인 없음, 서로이웃 호출 없음, "체류시간용" 분량 추가 없음. (R9)
- [ ] **문장 자체 점검 통과.** `human-prose.ko.md` §5 기준 S1 적발 0건, 글 전체에 어미 하나, `첫째/둘째/셋째` 뼈대·`결론적으로`·`도움이 되셨다면 공감과 댓글`·`지금 바로` 없음, 결과물 본문에 마크다운 `**`/`#` 없음.

### 계획 기본값 (보고만 하고 차단하지 않음)

- [ ] 본문 길이가 대략 1,500~3,000자 안에 있거나 벗어난 이유가 의도로 설명됨(짧은 실행 안내는 더 짧을 수 있음).
- [ ] 이미지 마커: 일반 글 5~12개(실행 안내는 단계마다 하나). 캡션은 라벨이 아니라 사실.
- [ ] 제목 20~35자, 목표 검색어가 앞 절반에, 이모지 없음.
- [ ] 단락 1~3문장. 소제목은 실제 탐색 지점에만(보통 3~6개).
- [ ] 장식: `human-prose.ko.md` §4에서 고른 행의 글당 상한 안.

### 전달 형태

- [ ] 제목 후보 3개와 추천 1개, `text` 코드 펜스, 키워드 결정 한 줄, 슬롯 목록, 발행 전 메모(모드, 에디터 주제, 공개 문장, 링크, 리서치 URL. 분량 메모는 기본값을 벗어날 때만).
- [ ] 사용자 대면 결과물에 규칙 ID, 등급 표시, 채점표 문구 없음.
