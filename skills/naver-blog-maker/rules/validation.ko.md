# 검증

> 영어 원본: [`validation.md`](validation.md)

**목적**: 전달 전 모든 초안에 실행하는 자체 점검과 이 스킬이 바뀔 때 실행하는 패키지 점검입니다. 각 항목은 모델이 세거나 볼 수 있는 것입니다. 점수도 스크립트도 없습니다.

## 1. 초안 점검표

### 강제 규칙 (하나라도 실패하면 전달 중단)

- [ ] **의도 하나, 레인 하나.** 글이 지정된 검색어 슬라이스 하나에 답하고 주제가 접수 때 기록한 작성자 블로그 레인에 맞음. (R1)
- [ ] **모든 섹션에 근거.** 각 섹션에 확인 가능한 상황(날짜, 장소, 기간, 가격 기준, 수량, 조건) 하나나 인용 출처가 있고, 최소 한 섹션이 아쉬운 점, 예외, 실패를 밝힘. (R2)
- [ ] **해결 계층 완결.** 의도나 제목이 무엇을 할지·고를지·얼마나 자주·얼마만큼·얼마 동안·얼마에 물을 때 해결 계층이 있음: 판단 기준 ≥1 · 사실 묶음에 출처가 있는 선택지 전부 · 적용되는 운영 수치 · 조언이 뒤집히는 조건 ≥1 · 다음 단계 정확히 1개. 유형이 결정 줄에 밝혀지고 본문이 그 유형의 골격을 따르며 보조 유형은 최대 1개.
- [ ] **실행 가능한 결정 데이터.** 사실 묶음에 검증된 서로 다른 정량 필드가 둘 이상이면 해결 계층이 그중 최소 둘을 씀. 하나만 검증됐으면 그것만 쓰고 해결되지 않은 항목을 발행 전 메모에 적음. 숫자를 만들어내지 않고 개수를 맞추려고 문장을 늘리지 않음. **이 항목은 이 스킬 자체의 완결성 기준이며 네이버 규칙이 아님.**
- [ ] **규제 수치 추적성.** 규제 주제의 모든 정량 주장이 `source_role`이 `quantitative_authority`인 1차 출처 행으로 추적됨(URL·날짜·`claim_scope` 포함). peer-reviewed 리뷰 같은 `supporting_context`는 숫자의 단독 근거가 아님. `source-required` 슬롯은 증거가 아니라 발행 차단 요인. 의료 주제는 `../references/regulated-topic-research.ko.md` §7~§8의 경계 gate도 통과함.
- [ ] **이미지에 숨긴 사실 없음.** 핵심 수치·가격·조건·절차가 본문 텍스트로도 존재함. 독자에게 필요한 것이 이미지만으로 전달되지 않음.

- [ ] **유형 선언과 준수.** 글 유형이 결정 줄에 밝혀지고 본문이 그 유형의 골격을 따르며 보조 유형은 최대 1개임.
- [ ] **삽입된 키워드 없음.** 목표 검색어가 제목에 한 번, 본문에서는 문장이 필요로 하는 자리에만 나옴. 본문을 소리 내 읽어 독자가 알아챌 반복이 없고, 숨긴 키워드나 무관한 키워드가 없으며, 해시태그는 7개 이하로 모두 정확함. (R3)
- [ ] **제목 약속 이행.** 제목이 암시하는 구체적 답이나 발견이 첫 3~5문장 안에 있음. 숨김 어휘(`이것`, `비밀`, `충격`), 만들어낸 통계, 가짜 기한 없음. (R4)
- [ ] **원본만.** 제공받은 업체 원고 없음, 다른 글에도 나오는 템플릿 블록 없음, 다른 글의 사진 세트를 가리키는 이미지 마커 없음. (R5)
- [ ] **공개와 링크.** 전환형이나 협찬·제휴 관계는 첫 단락에서 쉬운 말로 공개하고, 모든 외부 링크가 어디로 가는지 밝힘. (R6)
- [ ] **리서치 실행, 지어낸 것 없음.** 브리프에 사실이 없었으면 사실 묶음에 출처 있는 사실(`URL | 날짜`)과 상위 3편 빈틈 분석이 있고, 작성자가 주지 않은 직접 경험 주장은 모두 예시가 붙은 `[확인 필요: …]` 슬롯이지 문장이 아님.
- [ ] **인라인 이미지 마커.** 제목 뒤 커버 마커 하나와 사진으로 증명할 주장마다 `[이미지: 무엇을 찍을지 | 캡션]` 하나가 본문의 그 위치에 있음. 스톡·캡처·재사용 세트 제안 없음.
- [ ] **선택 양식 전달.** 시작 질문 답 확인. plain은 text 펜스 하나, rich는 제목·태그와 분리된 본문 HTML. HTML 클립보드 조건, HTTPS 이미지, 표 병합 확인. data:image·스크립트·이벤트 핸들러 제외.
- [ ] **사람이 검토할 초안 하나.** 글은 정확히 한 편, 묶음 발행용 변형 없음, 사실이 빠진 자리는 채우지 않고 `[확인 필요]` 표시를 남김. (R7)
- [ ] **브랜드 사실 원문 유지.** 전환형: 모든 가치입증 문장이 사용자 입력과 글자 단위로 일치하고 자격, 건수, 수상, 가격을 더하지 않음.
- [ ] **반응 조작 없음.** 댓글·좋아요·구독 유인 없음, 서로이웃 호출 없음, "체류시간용" 분량 추가 없음. (R9)
- [ ] **문장 자체 점검 통과.** `human-prose.ko.md` §5 기준 S1 적발 0건, 글 전체에 어미 하나, `첫째/둘째/셋째` 뼈대·`결론적으로`·`도움이 되셨다면 공감과 댓글`·`지금 바로` 없음, 결과물 본문에 마크다운 `**`/`#` 없음.
- [ ] **tell 카탈로그 확인.** 전달 전에 `references/tell-catalog.ko.md`를 패밀리별로 초안과 대조함. S1 항목은 나오는 곳마다 지웠고, S2·S3 편집은 우세 패턴 진단이 이름 붙인 패밀리 안에 머묾.

### 생성 시각 브리프 (하나라도 실패하면 전달 중단)

- [ ] `이미지 생성` 마커마다 `id`가 그 마커와 일치하는 JSON 객체가 정확히 하나 있고, 마커 없는 객체는 없음. 각 객체는 `json` 태그가 붙은 펜스로 전달되고 태그 없는 맨 펜스가 아님.
- [ ] 각 객체의 `section_role`이 14개 역할 중 하나이고, `template`이 `references/image-prompt-templates.ko.md` §2에서 그 역할 행의 템플릿 ID임.
- [ ] 상시 14개 필드가 모두 있고, 조건부 필드는 의미가 있을 때만 있음. 적용되지 않는 필드는 아예 없어야 하며 `null`, `"N/A"`, `"없음"`, `"위와 동일"`, 자리표시자로 채우지 않음.
- [ ] 그려질 글자가 `text[]` 안에서 정확히 한 번 나타나고 `prompt`가 그 모두를 byte 단위로 그대로 담음. 어느 한 표현 안에서도 번역·교정·축약하지 않고, `text[]` 안에서 같은 라벨을 두 번 나열하지 않으며, `prompt`가 모든 문구를 그대로 담음.
- [ ] 두 장 이상이 하나의 시리즈를 이루면 그 시리즈의 공통 조건이 시리즈의 모든 객체에 같게 반복되고, "위와 동일"이라고 쓴 객체가 없음.
- [ ] 제공된 자료는 `inspiration` 또는 `edit_source`로 표시되고, 편집 브리프에는 원본, 보존할 요소, 바꿀 범위가 적혀 있음.
- [ ] 제공자·모델·품질·해상도 플래그가 없고, 생존 작가·실존 인물·상표를 스타일 지름길로 빌린 객체가 없음.
- [ ] 생성 이미지가 실제 현장·장소·영수증·견적서·계기 판독값·결과·인증서·시공 전후 사진을 대신하지 않고, 실제 지리에 생성 지도를 쓰지 않음.
- [ ] `prompt`가 구조 필드만 다시 말하고 그 밖의 사실·브랜드·인물·숫자·파라미터를 도입하지 않음.

### 계획 기본값 (보고만 하고 차단하지 않음)

- [ ] 본문 길이가 대략 1,500~3,000자 안에 있거나 벗어난 이유가 의도로 설명됨(짧은 실행 안내는 더 짧을 수 있음).
- [ ] 밀도는 `image-slots.ko.md` §1을 참고하되 채우기 금지. 실제 자료와 생성 그림을 구분하고 생성 마커와 JSON id가 1:1 대응.
- [ ] 제목 20~35자, 목표 검색어가 앞 절반에, 이모지 없음.
- [ ] 단락 1~3문장. 소제목은 실제 탐색 지점에만(보통 3~6개).
- [ ] 장식: `human-prose.ko.md` §4에서 고른 행의 글당 상한 안.

### 전달 형태

- [ ] rich 파일은 서식 콘텐츠 복사 버튼을 포함하고 #sample만 선택함. 제목·태그·프롬프트는 밖에 있으며 복사 실패 시 수동 안내를 표시함.

- [ ] 제목 후보 → 선택 양식 본문 → 생성 JSON → 키워드 → 슬롯 → 발행 메모 순서.
- [ ] 사용자 대면 결과물에 규칙 ID, 등급 표시, 채점표 문구 없음.

### 수리 경로 (사용자가 글을 준 경우에만)

- [ ] 첫 편집 전에 앵커를 기록하고 편집 뒤에 다시 확인함: 사실, 숫자, 날짜, 이름, 가격, 소요 시간, 인용, 출처 표기, 이미지 마커, `[확인 필요]` 슬롯, 공개 문장, 브랜드 문장, 행동 유도 하나, 해시태그, 소제목, 목록·표 형태(`repair-method.ko.md` §2).
- [ ] 진단이 인용 예가 있는 패밀리 3~6개를 이름 붙였고, 편집이 그 패밀리와 찾아낸 S1 항목 안에 머묾.
- [ ] 어미가 양방향으로 그대로이고 줄임말, 옆길, 물음표, 독자에게 건네는 말이 살아남음.
- [ ] 고친 글에 대한 새 tell S1 스캔을 포함해 과교정 가드를 통과함.
- [ ] 의심스러운 편집은 밀어붙이지 않고 되돌림.
- [ ] 고친 글은 선택 양식으로 전달하고 변경 요약은 본문 밖에 둠.

## 2. 패키지 점검표 (이 스킬이 바뀔 때)
