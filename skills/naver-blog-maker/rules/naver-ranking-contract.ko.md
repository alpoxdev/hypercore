# 네이버 랭킹 계약

> 영어 원본: [`naver-ranking-contract.md`](naver-ranking-contract.md)

**목적**: 네이버 블로그 글이 현행 시스템(C-Rank, D.I.A.+, 스마트블록, LLM UGC 평가, AI 브리핑)에 노출될 수 있고 공식 제한 기준을 절대 건드리지 않도록 지켜야 하는 규칙입니다. 모든 규칙에 근거 등급을 붙여 무엇이 강제 규칙이고 무엇이 계획용 기준인지 구분합니다. 출처는 [`../references/naver-algorithm-timeline.ko.md`](../references/naver-algorithm-timeline.ko.md)에 있습니다.

## 1. 근거 등급

| 등급 | 뜻 | 적용 방법 |
|---|---|---|
| `official` | 네이버가 직접 발표한 내용(검색 공식블로그, 블로그팀 공식블로그, help.naver.com, searchadvisor.naver.com). | 강제 규칙. 위반하면 검증 실패. |
| `observed` | 독립적인 실무자 여러 명이 반복 확인했거나 실제 상위 글에서 측정했지만 네이버가 확인한 적은 없음. | 계획 기본값. 내용상 필요하면 벗어나되 사용자에게 네이버 규칙이라고 말하지 않음. |
| `folklore` | 널리 떠돌지만 네이버가 부정했거나 확인되지 않았거나 단일 출처. | 적용하지 않음. 사용자가 요구하면 한 문장으로 사실을 말하고 위 등급의 대안을 제시. |

## 2. 강제 규칙 (`official`)

### R1. 검색 의도 하나, 주제 레인 하나
- 네이버는 복합 검색어를 의도 단위(캠핑요리 / 캠핑용품 / 캠핑장소)로 나누고 스마트블록마다 따로 랭킹합니다. 글 하나는 의도 **하나**에 답합니다. 이것저것 다 담은 글은 어느 블록에서도 경쟁하지 못합니다.
- 글의 주제는 블로그가 이미 쌓아온 주제 레인에 맞아야 합니다. C-Rank는 *출처*의 주제별 신뢰도를 평가하고, 2026 가이드는 한 주제를 지속 발행하는 채널을 "전문 출처"라고 부릅니다. 레인 밖의 글은 레인을 키우지 못합니다.
- 발행 전 에디터에서 맞는 주제를 선택합니다(홈피드·주제판 자격 요건이지 보장은 아님).

### R2. 경험이나 검증 가능한 정보로 시작
- D.I.A.는 경험 정보, 정보 충실성, 독창성, 적시성을 명시합니다. 2025 LLM 평가는 "실제 경험에 기반하지 않은 광고성 도배글"을 겨냥합니다. 2026 가이드는 "직접 경험한 사람만이 알 수 있는 팁이나 주의 사항"을 요구합니다.
- 모든 섹션에 확인 가능한 상황(날짜, 장소, 기간, 가격 기준, 수량, 조건) 하나나 출처가 있는 사실 하나가 들어가야 합니다. 권유만 하는 섹션은 채우기용입니다.
- 사진과 캡션은 바로 옆 본문의 주장을 증명해야 합니다(D.I.A.+는 이미지 정보를 본문과 함께 읽음).

### R3. 키워드는 자연스럽게, 삽입하지 않음
- 제한 기준(help 5626/22928, 5593/10586): "제목 및 본문에 특정 키워드를 과도하게 삽입하여 방문을 유도", "본문에 숨겨진 키워드", "제목과 본문에 특정 단어를 삽입해 … 이용자가 의도치 않은 정보를 열람케 하는 내용".
- 규칙: 목표 검색어는 제목에 한 번, 본문에서는 문장이 정말 필요로 하는 자리에만 씁니다. 횟수 목표도 밀도 목표도 없습니다. 독자가 알아챌 반복은 실패입니다.
- 해시태그: 정확한 주제·개체 태그 몇 개. 키워드 목록으로 쓰지 않습니다.

### R4. 제목의 약속 = 본문의 이행
- 서치어드바이저는 낚시성을 제목·본문과 검색어의 불일치로 정의하고 순위 하락이나 제외를 결과로 명시하며, 독자가 제목만 보고 핵심 내용을 예측할 수 있어야 한다고 요구합니다. 2026 가이드도 낚시성을 불리 요소로 듭니다.
- 규칙: 제목이 암시하는 구체적 답이나 발견이 첫 화면(모바일 기준 첫 3~5문장) 안에 나옵니다. 호기심은 구체적이고 본문이 즉시 갚을 때만 허용합니다. 숨김("이것", "비밀", 만들어낸 퍼센트)은 실패입니다.

### R5. 원본 글과 원본 이미지만
- 유사문서 판독은 원본과 복사본을 구분합니다. 복사·스크랩·기계적 재작성·제공 원고는 제한됩니다. 글마다 거의 같은 사진을 재사용하는 것도 지양 대상입니다(홈피드 가이드).
- 규칙: 붙여 넣은 업체 원고 없음, 글 사이에 재사용하는 템플릿 블록 없음, 이전 글 이미지 세트 재활용 없음.

### R6. 기만적 링크 없음, 상업적 관계 미공개 없음
- 제한: "명확히 고지되지 않은 이미지 또는 텍스트 링크로 외부 사이트로 유도". 이달의 블로그 제외 사유에 공정위 광고 표시 지침 위반이 있습니다.
- 규칙: 모든 외부 링크는 어디로 가는지 밝힙니다. 협찬·무료 제품·원고료는 평가 문장보다 앞선 서두에 쉬운 말로 공개합니다("~로부터 제품/원고료를 제공받아 작성했습니다"). 숨긴 태그나 "지원"만으로는 실패입니다.

### R7. AI 보조는 괜찮고 AI 대량 생산은 안 됨
- 공식(2024-02-28, 2026-05-26, 2026-07-06): AI 사용 자체는 불이익 사유가 아니며 "특정 기술의 활용 여부만으로는 판단하지 않습니다". 제한 대상은 AI만으로 자동 발행, 앞뒤 안 맞는 반복, 동일·유사 템플릿 대량 생산, 복사·짜깁기입니다.
- 규칙: 이 스킬은 **사람이 검토할 초안 하나**를 만듭니다. 묶음 생산도 자동 발행도 하지 않습니다. 사용자 블로그 관례나 'AI 활용' 설정이 요구하면 AI 보조를 공개합니다.

### R8. 모바일에서 읽히는 구조
- D.I.A.+는 문서 구조를 읽고, 2026 가이드는 읽기 쉬운 구조와 맥락에 맞는 미디어를 요구합니다.
- 규칙: 단락 하나에 생각 하나(1~3문장), 소제목은 실제 탐색 지점에만, 비교는 표, 절차는 목록, 이미지는 뒷받침하는 주장 바로 옆에.

### R9. 반응을 만들어내지 않음
- 스팸 사례(2026-07-06)와 이달의 블로그 제외 사유는 인위적 트래픽·댓글·추천과 이웃 추가 유도를 듭니다. "이용자 선호도"는 네이버가 읽는 신호군이고, 공개된 유일한 체류시간 활용(2016 스크롤 로그)은 결과 영역 순서에 쓰였을 뿐 개별 글에는 쓰이지 않았습니다. 작성자가 흉내 내거나 목표로 삼을 대상이 아닙니다.
- 규칙: "댓글 남기면 ~드려요" 유인 없음, 좋아요·구독 압박 없음, 서로이웃 호출 없음, "체류시간을 늘리려고" 분량 추가 없음. 대신 독자의 과제 완료를 최적화합니다.

### R10. 핵심 정보는 이미지가 아니라 텍스트에
- 서치어드바이저 콘텐츠 가이드: "검색로봇은 이미지 속 텍스트를 인식하기 어려우므로 사이트 내 핵심 정보는 가급적 텍스트로 작성해 주세요."
- 규칙: 가격·수치·조건·절차처럼 독자가 검색으로 찾는 정보는 본문 문장으로 존재해야 합니다. 이미지·인포그래픽은 보조이며 그 정보를 대체하지 않습니다.
- 적용 범위: 네이버가 발행한 사이트 콘텐츠 지침을 이 스킬의 작성 규칙으로 옮긴 것입니다. 네이버 블로그의 랭킹 규칙으로 독립 확인된 것은 아니므로 그렇게 말하지 않습니다.
- 출처: <https://searchadvisor.naver.com/guide/content-basic> (official, 날짜 없음; 접근 2026-09-17)

## 3. 계획 기본값 (`observed`)

초안 크기를 잡을 때 씁니다. 사용자에게는 기본값이라고 말하고 필수 조건이라고 하지 않습니다.

| 항목 | 기본값 | observed에 머무는 이유 |
|---|---|---|
| 본문 길이 | 정보·후기 글은 본문만 1,500~3,000자. 의도에 답했으면 멈춤 | 실무자 의견이 갈림(상위 글 실측 1,200~1,800, 의견 1,500~2,000, 2,000~4,000). 네이버 수치 없음 |
| 이미지 | 커버 + 사진으로 증명할 수 있는 주장마다 하나. 보통 5~12장 | 공식: 이미지 정보를 읽음. 개수 없음 |
| 제목 | 20~35자, 목표 검색어를 앞쪽에, 구체적 보상 | 입력 한도 40자. 앞쪽 배치는 모바일 잘림 때문이지 랭킹 규칙이 아님 |
| 소제목 | 독자 질문 하나에 하나, 보통 3~6개 | 구조는 공식이나 개수는 아님 |
| 첫 화면 | 첫 3~5문장 안에 답, 범위, 신뢰 근거(경험/출처) | R4에서 따라옴. "2~3줄"은 실무자 수치 |
| 발행 시간 | 작성자 자신의 통계 피크 1~2시간 전 | 개인 분석만 있음. 보편 시간 없음 |
| 최신성 | 사실이 바뀌면 갱신하거나 날짜 변경 | 적시성은 공식이나 주기는 아님 |

## 4. 속설 — 적용하지 않음

| 주장 | 실패 이유 |
|---|---|
| "1,500자 이상 필수", "이미지 5장 이상", "키워드 3~5회" | 공식 수치 없음. 출처끼리 모순. 측정 표본은 하나뿐 |
| "블로그 지수", "최적화/준최적화 블로그" | 네이버: "네이버에서 만든 개념이 아닙니다" |
| "1일 1포스팅 / 발행량이 C-Rank를 올린다" | C-Rank FAQ: 문서 수만으로는 유리하지 않음. D.I.A.는 작성 주기와 무관 |
| "AI로 쓰면 저품질" | 공식적으로 세 번 부정(2024-02, 2026-05, 2026-07). 불이익은 대량·템플릿 생산과 연관 |
| "같은 IP/와이파이면 저품질" | 2016-07-12 공식 부정 |
| "체류시간 0이면 감점" / 고정 체류 임계값 | 이용자 선호도는 신호이나 지표나 임계값은 공개된 적 없음 |
| "상업 키워드는 자동 저품질" | 실제 조치 조건은 기만, 미공개, 반복 유료 후기, 비경험 원고이며 키워드 자체가 아님 |
| "C-Rank 2.0", "2025년 3월 대란" | 공식 용어나 사건이 아님. 가장 가까운 공식 사건은 2025-02-28 공지 |
| 백링크, 스키마, 메타 디스크립션, Core Web Vitals | 구글 요소. blog.naver.com에서는 작성자가 제어할 수 없고 네이버가 명시한 적 없음 |

## 5. 구글과 다른 점

| 구글 요소 | 네이버 블로그에서는 |
|---|---|
| 백링크 / PageRank | 명시된 신호 아님. 출처 신뢰는 주제 레인 일관성(C-Rank) |
| E-E-A-T | 대응물은 직접 경험 + 일관된 주제 이력. 작성자 스키마 없음 |
| 기술 SEO(CWV, 스키마, canonical, 사이트맵, Search Console) | 네이버가 템플릿과 호스팅을 소유. 제어 불가 |
| `<title>` / 메타 디스크립션 | 보이는 글 제목과 첫 화면만 존재 |
| 권위 전달용 내부 링크 | 링크는 독자가 이어 읽게 돕는 용도. 그래프 권위 주장 없음 |
| Helpful Content | 방향이 같음. 경험, 독창성, 충실성, 가독성 |
| 결과 화면 | 파란 링크 열 개가 아님. 블로그·카페·동영상·지식iN을 섞은 의도별 스마트블록, AI 브리핑 인용, 홈피드 추천 |
