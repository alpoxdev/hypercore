Use this skill when work must continue from a short state memo, not the long conversation: the context is nearly full, the session is to be compacted, replaced, or moved to another agent or machine, or the user asks for a handoff, a continuation note, or to read, restate, or continue from a named memo under `.hyper/handoff/`, even when its HEAD or dirty files no longer match the repository (it reports the mismatch). Do not use for durable agent memory files, for a written work plan, for the run state of a plan or goal loop, for a chat summary, or for a plain request to continue that names no memo while none is open. It writes one memo file under `.hyper/handoff/` holding the original request verbatim, what is being done and why, what is verified, the next steps, the plan, done-when conditions, and locations; proves the memo stands alone by having a reader with no conversation answer fixed questions; and starts a fresh session from that memo alone, restating it in three lines before the work continues.
