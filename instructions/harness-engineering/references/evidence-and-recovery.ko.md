# Evidence and Recovery Reference

> 영어판: [`evidence-and-recovery.md`](evidence-and-recovery.md)

증거·검증 비용 축소·장기 실행 복구에 대한 하네스 규칙의 유도다.
**규범**은 [`HARNESS_ENGINEERING.ko.md`](../HARNESS_ENGINEERING.ko.md)의 `## Evidence Discipline`,
`## Reducing Verification Cost`, `## Long-Horizon Recovery`에 있다. 이 문서는 각 규칙의 작업 형태를 보이고,
**원리**와 특정 저장소의 **구현**을 구분한다.

## 증거 규율

### 하나의 해석된 경로

증거 디렉터리는 **손으로 적지 않고 해석한다**. 손으로 적은 경로는 아무 리뷰어도 읽지 않고
어떤 pull request도 인용할 수 없는 곳에 남는다. 해석기는 절대 경로를 돌려주고 아무것도 만들지
않으며, 상위 이동·구분자·절대 경로 입력·git 루트 밖을 거부한다. 해석기는 자체 테스트를 함께
두어, 망가진 해석기가 잘못된 증거를 만들기 전에 실패하게 한다.

**원리**(이식 가능): 증거 위치는 계산하지, 주장하지 않는다.
**구현**(규모 의존): 거부 규칙의 정확한 목록과 그것을 강제하는 스크립트.

### 증거 README 4절

| 절 | 들어갈 것 |
|---|---|
| 무엇을 시험했는가 | 명령, 표면, 리비전 |
| 무엇을 관찰했는가 | 원문 출력 또는 충실한 발췌 — 요약이 아니다 |
| 왜 그것으로 충분한가 | 어느 게이트를 만족하는지, 무엇은 덮지 않는지 |
| 무엇을 생략했는가 | 가린 것과 그 이유 — 비밀·토큰·헤더·env 덤프 |

네 번째 절은 선택이 아니다. 읽는 사람이 **증거에 구멍이 있다는 것을 알게 되는 자리**다.

### 실사용 증명과 단위 게이트는 다른 주장이다

hermetic 단위 게이트와 실제 표면 실행은 다른 것을 증명한다. 둘 다 두고, 어느 쪽을 돌렸는지
표시한다. 단위 스위트 통과는 실사용 증명이 아니고, 단위 스위트를 건너뛴 실사용 실행은 회귀
방어가 아니다.

### 격리는 주장하지 않고 입증한다

| 필드 | 왜 필요한가 |
|---|---|
| 건드리지 않은 실제 설정·DB의 전후 digest | 실행이 실물을 건드리지 않았음을 보인다 |
| 변경된 경로 목록 | 실행이 실제로 쓴 것을 보인다 |
| 격리 디렉터리 경로 | 리뷰어가 샌드박스 자체를 볼 수 있게 한다 |

디렉터리 전체 digest는 보조 증거이지, 그것만으로 증명이 아니다.

### 실행 불가는 통과가 아니다

바이너리·자격증명·네트워크가 없어 실행하지 못했으면 `SKIP`으로 기록하고 증거 README에 그렇게
적는다. **`SKIP`은 통과가 아니다.** skip을 통과로 세는 순간 게이트가 아무것도 덮지 않게 된다.

## 검증 비용 축소

비싼 검증을 줄이는 것은 정당하다. 그것을 **산문으로** 하는 것은 아니다.

축소 결정은 durable 상태에서 계산한다. 위험 등급, 변경의 크기와 모양, 변경 집합이 완전히
포착됐는지, 소스 기준 해시가 있는지다. 자유 서술은 축소를 승인할 수 없다. 줄이려는 대상이
바로 그 서술에 대한 검사이기 때문이다.

방어 가능한 축소의 모양:

```
riskClass: low
reasons: [단일 미완 목표, 집계 모양을 앎, 고위험 경로 미접촉]
omittedLanes: [비싼 리뷰 레인]
sourceBasisDigest: <해시>
```

불변식 둘:

- **증명은 계산된 선택과 정확히 일치해야 한다.** 불일치는 판단 문제가 아니라 실패이며,
  전체 검사 집합이 그대로 유지된다.
- **최소 한 개의 레인은 절대 생략할 수 없다.** 실제 표면에 대한 대상 검증은 모든 경계에서
  돈다. 줄어들 수 있는 것은 비싼 리뷰이지, 동작한다는 증거가 아니다.

해시가 없거나 검증되지 않으면 fail-closed다. 해시는 통합 기준, 정규화된 경로/상태 행, 캡처된
diff, 추적되지 않은 파일의 내용을 묶고, 심볼릭 링크 대상은 따라가지 않는다.

**원리**(이식 가능): 축소는 계산하고, 대조하고, fail-closed로 만든다.
**구현**(규모 의존): 어떤 레인이 있고, 위험 등급의 이름이 무엇이며, 해시의 정확한 구성.

## 장기 실행 복구

### 압축 후에도 살아남아야 하는 것

대화는 남기고 계약을 잃은 압축은 작업을 파괴한 것이다. 살아남아야 하는 목록:

- 활성 목표,
- 수용된 범위와 명시적 비목표,
- 수용 기준,
- 현재 단계와 다음 행동,
- 이미 기록된 블로커.

### 복구 투영은 읽기 전용이고 조용히 퇴화한다

복구는 정본 durable 상태를 읽기 전용으로 읽는다. 잘못되거나 낡았거나 읽을 수 없거나 변조된
상태를 만난 투영은 아무것도 돌려주지 않고, 시스템은 더 얇은 투영으로 퇴화한다.
**투영 실패가 압축 자체를 중단시켜서는 안 된다** — 복구 장치의 실패 모드가, 그것이 막으려는
실패보다 나쁠 수는 없다.

### 반복을 유계로 만든다 — 제거한다고 주장하지 않는다

같은 다음 행동으로 되돌아오는 복구는 정체다. 시도마다 투영을 지문으로 찍고, 변화 없는 복구가
몇 번 이어지면 명시적 `STALLED` 지시를 내보내 같은 행동을 반복하는 대신 durable 블로커나
에스컬레이션을 지시한다.

"이것이 반복을 **유계로 만든다**"고 쓰고, "제거한다"고 쓰지 않는다. 유계는 정직하고, 제거는
뒷받침할 수 없는 주장이다.

**원리**(이식 가능): 살아남을 것을 적고, 안전하게 퇴화하고, 반복을 유계로 만든다.
**구현**(규모 의존): 정확한 임계값, 투영의 파일 형식, 해시 알고리즘.
